# Screenshots

This folder contains sanitized screenshots used as validation evidence for the managed network infrastructure lab.

## Screenshot Categories

| Category | Purpose |
|---|---|
| Omada Controller | Device adoption, topology, router/switch status |
| ER605 Router | WAN/LAN status, DHCP, routing validation |
| Managed Switch | Port overview and connectivity |
| Deco AP Mode | Wireless AP-mode validation |
| Pi-hole | DNS query and HA DNS validation |
| Grafana / Prometheus | Monitoring validation |
| Client Testing | DHCP, DNS, and internet validation |

## Sanitization Requirements

Before publishing screenshots, redact:

- Public WAN IP addresses
- MAC addresses
- Serial numbers
- Email addresses
- Device names that should remain private
- API keys, tokens, and secrets
