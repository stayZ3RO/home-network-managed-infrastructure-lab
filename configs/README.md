# Configs

This folder is used for sanitized configuration examples only.

## Folder Structure

| Folder | Purpose |
|---|---|
| examples/ | Example configs safe for public reference |
| sanitized/ | Redacted configuration snippets |

## Security Notes

Do not commit:

- Passwords
- API keys
- Private keys
- VPN profiles
- Raw router exports
- Raw switch exports
- Public IP information
- Authentication tokens
